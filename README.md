# 🌤️ Flask Weather App

A lightweight web application built with Python and Flask that provides real-time weather details—including temperature, humidity, and wind speed—for any searched city.

## 🚀 Features

- **City Search:** Instant real-time weather lookup.
- **Detailed Metrics:** Displays temperature, humidity, and wind conditions.
- **Clean UI:** Responsive and minimal user interface.

## 🛠️ Getting Started

### Prerequisites

Make sure you have Python installed on your system.

### Installation

1. Clone the repository:
   ```bash
   git clone [https://github.com/nilayperktas/py.git](https://github.com/nilayperktas/py.git)
   cd py
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the application:
   ```bash
   python main.py
   ```

4. Open your browser and navigate to:
   ```text
   [http://127.0.0.1:5000](http://127.0.0.1:5000)
   ```
